    📖 系統使用與設定教學


    1. 步驟 1： 前往 Google AI Studio 並登入 Google 帳號。
    2. 步驟 2： 點擊左上角的 「Get API key」 按鈕。
    3. 步驟 3： 點擊 「Create API key」，選擇專案或新建專案後產生 Key。
    4. 步驟 4： 複製生成的 API Key（開頭為 AIzaSy...）。
    5. 步驟 5： 回到本網站，點擊左側 「⚙️ API / GitHub 設定」，將 Key 貼入 Gemini API Key 欄位並點選儲存即可。
    1. 步驟 1 (建立 Repo)： 登入 GitHub，建立一個新的公開或私有儲存庫（例如：my-circuit-notes）。
    2. 步驟 2 (申請 PAT Token)： 前往 GitHub 的 Settings > Developer Settings > Personal Access Tokens > Tokens (classic)。
    3. 步驟 3 (勾選權限)： 點擊 Generate new token，名稱隨意填寫，存取權限務必勾選 repo 全項。
    4. 步驟 4 (複製 Token)： 複製生成的 Token（開頭為 ghp_...，僅會顯示一次！）。
    5. 步驟 5 (綁定設定)： 點擊本站左側 「⚙️ API / GitHub 設定」：
      • PAT Token： 貼上剛複製的 ghp_...
      • 用戶名 / Repo： 填寫 帳號/儲存庫名稱（如：iris5618/my-circuit-notes）
      • 目標路徑： 填寫 data.json
    6. 步驟 6 (備份筆記)： 日後新增筆記或 AI 解題後，點擊右上角 「☁️ 一鍵同步至 GitHub」，即可自動將資料備份並更新至 GitHub 倉庫！
